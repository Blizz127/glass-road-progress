# Glass Road progress

A small static page that logs the progress of Glass Road, an original game being built on a custom Rust and Vulkan engine. It shows a newest-first timeline of milestones with before-and-after test renders, short looping clips, and a quest log of engine features.

The page has no external scripts, fonts or services, and every path is relative. It is generated from private test runs and published as-is with GitHub Pages.
